# 从零复刻这个项目 · 教学手册

> 写给：会用一点 OpenCV（灰度、阈值、掩码、findContours 画框），
> 但**没把零件装成过一台完整机器**的人。
>
> 目标不是"能跑"，而是：合上代码，你能在白纸上画出整条流水线，
> 能解释每个数字为什么是那个值，能自己从零写一个能通关的版本。

---

## 〇、先诊断：你现在的水平

根据问卷，你的情况不是"零基础"，而是**零件齐全、缺连接线**：

| 你已经有的 | 你缺的 |
|---|---|
| 图像 = numpy 数组，H×W×C | 位图坐标 / CSS 坐标 / 屏幕坐标 的换算 |
| BGR、alpha 的概念 | 把 alpha 真正当掩码用（你只是"知道"） |
| 灰度、阈值、掩码 | 连通域、填充率、形状筛选 |
| Canny、findContours、画框 | 模板匹配 / NCC（"两张图像不像"的数学） |
| YOLO 输出框+类别+置信度 | 分类模型的输出（概率、top-k）、训练与数据划分 |
| 跑过项目、看它动 | 指派问题（谁去哪一格）、拖拽状态机 |

所以课程会**跳过**"什么是像素"，直接从"像素怎么变成坐标"开始；
形态学（腐蚀/膨胀）这个项目最终**没有用到**，先不学，省下的时间放在 NCC 和状态机上。

## 一、一张图看懂整个项目

```
             ┌──────────────┐
  屏幕/画布  │  1039×698×4  │  一个 numpy 数组：高、宽、BGRA
             └──────┬───────┘
                    │ ① alpha 掩码：哪些像素"有东西"
                    ▼
        ┌───────────────────────────┐
        │ 棋盘（暗、实心、矩形）      │ ② 连通域 + 填充率 → board
        │ 碎片（亮/彩色、有卡扣）     │
        └───────────┬───────────────┘
                    │ ③ 槽位公式：碎片不是"分割"出来的，是"算"出来的
                    ▼
  每块碎片：位置(x,y) + 四边(凸/凹/直) + 是不是纯白
                    │
                    │ ④ 参考图（Part 3 就是源图）切成 25 格
                    ▼
  25×20 的相似度矩阵 —— 每块照片碎片和每个照片格"有多像"（NCC）
                    │ ⑤ 加上 YOLO 的类别先验（同类加分、异类减分）
                    ▼
  指派：20 块碎片 ↔ 20 个照片格，一一对应，总分最大（匈牙利）
        剩下 5 块 = 混淆块；5 块纯白碎片用 5! 穷举配 5 个白格
                    │ ⑥ 按"外圈→内圈"顺序拖拽
                    ▼
  鼠标按下 → 移动 → 松开；看进度条涨没涨
        涨了 = 这块放对了；没涨 = 拖回去，换个候选/换块
```

**一句话总结**：
> 这个项目不是"让 AI 看图拼图"，而是**把拼图变成一个可以计算的匹配问题**：
> 碎片是"查询"，格子是"候选"，NCC 是"相似度"，匈牙利是"怎么配最划算"，
> 环形顺序 + 吸附反馈是"怎么把答案稳妥地执行出来"。

## 二、你问的三个问题（先给结论，细节在后面章节）

### Q1：为什么能拖这么快？

因为程序**不是在"看"，而是在"算"**：

1. 整局只截 **1 帧**画布（`capture_pieces` 默认不逐块点击），30 块碎片的位置、卡扣、白片判定
   全部从这一帧算出来，耗时 **0.02 秒**；
2. 每块碎片的"目的地"在拖之前就确定了，拖拽只是"把已知坐标变成 4 个鼠标事件"：
   `move → down → move → up`，没有人类那种"看着移、边移边修正"的过程；
3. 游戏吸附半径是 `0.14 × 碎片宽 ≈ 13.6px`，落点不需要像素级精确，
   槽位公式的误差只有 2.7–3.2px，天然落在半径内；
4. 一次拖拽实测 ~60–80ms，25 块 ≈ 2 秒。

所以"快"不是手速，是**不需要边做边想**。

### Q2：怎么知道碎片属于哪一格？

Part 3 有一个别的部分没有的条件：**右侧参考图就是拼图源图本身**
（源码 `renderMixedPuzzle()` 里 `updatePreviewImage(canvas.toDataURL())`）。
碎片正是从这张图切下来的，所以：

1. 把参考图切成 25 格，把每块碎片裁出中心 62%；
2. 两者缩到同尺寸、转 Lab、去均值、归一化，算 **NCC**（越接近 1 越像）；
3. 得到 **25 块照片碎片**（20 块真碎片 + 5 块混淆块）× 20 个照片格 的分数矩阵；
4. YOLO 给每块碎片一个类别，同类别 +0.10、top3 +0.04、top5 外 −0.06（类别只做"倾向"，不做硬性）；
5. **匈牙利算法**在"一一对应"的约束下选总分最大的一组；
6. 没被选中的 5 块，就是永远吸不上的**混淆块**。

### Q3：拖拽策略是什么？

1. **顺序**：外圈 → 内圈（`ring_order()`）。因为游戏有**锚点规则**：
   内部格子必须已经有一个邻居放好，才允许吸附；
2. **首选**：每格先拖"指派阶段"给它的那块；
3. **失败**：没吸上 → 立刻拖回原位 → 用画面校验它到底在哪 →
   下一轮换按"邻边吻合度"排序的候选；
4. **兜底**：所有格都试完还有空格，就把之前判为混淆的 5 块放回候选再试（防止误杀）。

## 三、课程表（9 章，建议 2 周，每天 1–1.5 小时）

> 每章都有：**要解决的问题 → 你会学到 → 对应代码 → 练习 → 验收**。
> 练习都在 `teaching/` 下，能直接跑，不依赖开浏览器。

### 第 1 章 像素、通道、alpha、坐标
- 解决：截图为啥是 1039×698×4？透明区为什么不能看颜色？
- 学到：`[y, x]` 顺序、alpha 掩码、不透明覆盖率、位图坐标 vs CSS 坐标 vs 屏幕坐标
- 代码：`teaching/l1_pixels.py`、`src/slots.py: alpha_mask`
- 练习：跑 `l1_pixels.py`，把阈值 250 改成 200，看掩码变化；解释为什么变多
- 验收：能说清"为什么 alpha 阈值调低，掩码会变大"

### 第 2 章 找到棋盘（连通域 + 填充率）
- 解决：画面里这么多不透明像素，哪个是棋盘？
- 学到：`connectedComponentsWithStats`、外接框、填充率 `area/(w*h)`、为什么不能用"最白的区域"
- 代码：`teaching/l2_board.py`、`src/pipeline.py: detect_board`
- 实测：空棋盘 fill=1.0；模拟 12 块碎片压上去后 fill=0.609 → 所以阈值只能取 0.25
- 练习：改 `BOARD_DARK_MAX`（30 / 200）和 fill 阈值（0.90），看棋盘什么时候消失/误杀
- 验收：能解释"填充率 > 0.25 而不是 0.9"的原因（碎片会盖住棋盘）

### 第 3 章 找到碎片：为什么"槽位锚定"而不是"分割"
- 解决：照片碎片颜色千变万化，阈值分割会碎成一堆；相邻碎片还会粘连
- 学到：引擎的托盘公式（槽距 1.16×碎片）、`occupied_slots`、中心 62% 裁剪、为什么不用逐块点击
- 代码：`src/slots.py: tray_slots / occupied_slots / crop_piece`、`play_p3.py: capture_pieces`
- 练习：在 `l1_grid.png` 上量一量相邻碎片的间距，验证 1.16 倍
- 验收：能画出"棋盘 + 左右托盘"的坐标草图，并算出第 7 个槽位的 x

### 第 4 章 判断四条边：凸 / 凹 / 直
- 解决：纯白碎片没有图案，只能靠轮廓几何
- 学到：在每条边"外侧一个窗口、内侧一个窗口"统计 alpha 覆盖率 → 密度 → 三分类；
  为什么凹槽会把邻居带进来（所以窗口要窄）
- 代码：`teaching/l4_edges.py`、`teaching/l4_thresholds.py`、`src/slots.py: edges_at_slot / label_from_density`
- 阈值来源：120 条边的 out/inn 直方图是双峰的，0.15/0.50/0.70 放在谷底；阈值与取样窗口绑定
- 实测：120 条边里 46 凸 / 53 凹 / 16 直 / 5 个拿不准（被邻片压住）
- 练习：拿一块白色碎片，手算它四条边的两个密度值
- 验收：能解释 `0.70 / 0.50 / 0.15` 三个阈值分别在分什么

### 第 5 章 参考图与 NCC（本项目的心脏）
- 解决："两张图像不像"怎么变成数字
- 学到：为什么必须"同视野"（都取中心 62%）、Lab 颜色空间、去均值、归一化、三通道平均；
  NCC 为什么对亮度整体变化不敏感
- 代码：`teaching/l6_ncc.py`、`play_p3.py: preview_native / split_cells / similarity / cell_crop`
- 实测：正确对中位 0.765，错误对中位 0.002，margin 中位 0.521，top-1 20/20；0.45 只是置信度门限，硬指派靠匈牙利
- 练习：把 `similarity()` 里的 `M` 打印出来，看"正确对"和"错误对"的分数分布差多少
- 验收：能手算两个 3×3 小矩阵的 NCC，并解释为什么"全白图"的 NCC 没有意义

### 第 6 章 YOLO：分类、概率、类别先验
- 解决：YOLO 在这个项目里到底干嘛？为什么不是"YOLO 直接给坐标"
- 学到：检测 vs 分类、softmax 输出、top-1/top-k、置信度、数据集怎么来（采集→题库自动标注→按原图划分）、
  类别先验的权重为什么只有 0.10（不能盖过 NCC）
- 代码：`play_p3.py: load_model / classify / apply_prior`、`tools/collect_p3.py / label_p3.py / build_p3_dataset.py`
- 练习：把 `apply_prior` 的权重改成 1.0，跑一局，看会不会变差；想为什么
- 验收：能解释"训练集按对局划分"为什么会虚高

### 第 7 章 指派：谁去哪一格
- 解决：每块碎片都有一个最高分格子，但可能撞车（两块都想同一格）
- 学到：贪心为什么不够、匈牙利算法在做什么（可以先用黑盒）、纯白 5! 穷举
- 代码：`play_p3.py: assign / _hungarian / white_plan`
- 练习：构造一个 3×3 分数矩阵，让贪心选错、匈牙利选对
- 验收：能说出"为什么 5 块纯白可以穷举，25 块照片不行"（120 vs 25!）

### 第 8 章 执行：锚点、吸附、状态机
- 解决：知道答案 ≠ 能放上去
- 学到：锚点规则、吸附半径、拖拽的 4 个鼠标事件、失败回拖、画面校验、候选池
- 代码：`play_p3.py: ring_order / execute / there / locate`
- 练习：把 `ring_order` 改成"按行优先"，跑一局，观察失败率变化
- 验收：能画出"一次拖拽"的状态转移图（在托盘 → 拖动中 → 落点 → 吸附/未吸附 → 回拖）

### 第 9 章 工程化与复刻
- 解决：为什么"本地能跑"和"稳定能跑"差很远
- 学到：开题时序（默认主题覆盖）、重试、日志、"以画面为准"、合规边界
- 代码：`play_p3.py: settle / start_part3`、`src/net.py: open_page`
- 练习：断网重跑，观察程序怎么重试；看 `logs/*_report.json` 里有哪些字段
- 验收：能独立写出"从打开页面到第一帧可用画面"的 30 行代码

## 四、怎么学（比课程表更重要）

1. **费曼法**：每章学完，合上代码，用 5 句话讲给一个不懂的人听。讲不顺的地方就是没懂。
2. **改一个数，看一个结果**：每个阈值（250、0.70、0.14、0.10）都改一次，
   观察输出怎么变。**你对参数的手感，来自你改坏过多少次。**
3. **画图**：坐标系、分数矩阵、状态机，全部画在纸上。这个项目的难点都是"空间关系"，
   不是代码语法。
4. **不要背代码**：记住"每一步在解决什么问题"，代码忘了可以查，问题忘了就全忘了。

## 五、术语表（说人话版）

| 词 | 说人话 |
|---|---|
| 通道 / channel | 一张图每个像素存了几个数：B、G、R、A 四个 |
| alpha | 第 4 个数，0=全透明，255=完全不透明 |
| 掩码 / mask | 一张只有 0/1 的图，1 的地方是"我要的像素" |
| 连通域 | 把挨在一起的 1 归成一块，数一共有几块 |
| 填充率 | 连通域面积 ÷ 外接框面积，越接近 1 越"实心" |
| NCC | 把两张图都减去平均值再归一化，算点积；1=完全一样，0=没关系，−1=反着像 |
| top-k | 分类模型给出的概率最高的 k 个类别 |
| 置信度 | 模型对这个答案有多确定（0~1，不是准确率） |
| 指派 / 匈牙利 | 一群人分任务，每人一个，怎么分总分最高 |
| 锚点 | 游戏规则：内部格子必须已有邻居放好才让吸附 |
| 吸附半径 | 松手时离正确位置多近才算放对（5×5 时 13.6px） |
| 混淆块 | 多出来的、永远放不进去的干扰碎片 |

## 六、复刻路线（两条，选一条）

### 路线 A：先跑通，再拆零件（推荐给现在的你）
1. 跑 `play_p3.py --dry-run`，看它打印的 20 对指派；
2. 用 `teaching/l1_pixels.py` 把一帧拆开看；
3. 按第 1→9 章，每章只改一个函数，改完跑 `--dry-run` 验证；
4. 最后把 `play_p3.py` 删掉，凭记忆重写一遍（允许查文档，不允许抄）。

### 路线 B：从零搭（适合已经学完 1–5 章）
1. 先写"截图 + 找棋盘 + 画框"（50 行）；
2. 再加"槽位取碎片 + 画 30 个框"；
3. 再加"参考图切格 + 分数矩阵"，先用 `print` 看矩阵；
4. 最后才接鼠标。

两条路都以"能解释每个数字"为终点，不以"能跑"为终点。
